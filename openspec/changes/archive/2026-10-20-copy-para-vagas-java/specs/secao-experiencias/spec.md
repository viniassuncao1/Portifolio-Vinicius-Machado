# Spec Delta

## MODIFIED Requirements

### Requirement: Destaques de cada experiência
Cada experiência SHALL incluir as responsabilidades e realizações, como texto em bloco de
comentário ou lista de destaques. O cargo atual na Memora MUST citar as tecnologias do dia a dia:
APIs REST em Java 21 e Spring Boot com JPA e Spring Security, microsserviços (login, gateway,
financeiro e RH), componentes em Angular 17 integrados às APIs, GitLab CI/CD com Docker e
Kubernetes, e a liderança de squad no Scrum.

#### Scenario: Estágio na Memora
- **WHEN** o visitante chega ao estágio na Memora
- **THEN** ele cita a migração de Oracle para PostgreSQL, os scrapers em Java com Playwright e o AyoForms

#### Scenario: Cargo atual na Memora
- **WHEN** o visitante chega ao cargo atual na Memora
- **THEN** os destaques citam Java 21, Spring Boot, Spring Security, microsserviços, Angular 17 e
  GitLab CI/CD, além da liderança de squad

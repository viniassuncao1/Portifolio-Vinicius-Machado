# Spec Delta

## ADDED Requirements

### Requirement: Ícones oficiais com créditos
Os ícones da interface SHALL vir do conjunto da New UI da IntelliJ Platform (tema escuro),
servidos pelo próprio site, com um arquivo de créditos que cita a origem, o aviso de copyright e
a licença Apache 2.0. Logotipos de produtos e marcas da JetBrains MUST NOT ser usados.

#### Scenario: Créditos publicados
- **WHEN** alguém procura a origem dos ícones no repositório
- **THEN** encontra o arquivo de créditos com a origem, o copyright e a licença, citado no README
